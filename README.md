# Apex-NASA-Health_Monitor
Developed for NASA Space Apps Challenge.
Made in Python on VS Code on Fedora.

-Notice-
This software is not very accurate! It is for educational purposes only.

-Installation-
Install python, and requirements in the text file:
pip install -r requirements.txt
...or execute this command:
pip install questionary

-Instructions- 
Running the terminal in the same folder, you can run the file:
python main.py

There are two modes, random is by default. It generates all the information completely random. Command:
python main.py 
or
python main.py r

The second mode is JSON mode, it reads information in a JSON file (default is artemis.json). Command:
python main.py j
